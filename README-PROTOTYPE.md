# Prototype Landing Page Implementation

This directory contains a pixel-accurate implementation of the landing page based on prototype screenshots.

## Components

All components are located in `/src/components/prototype/`:

- **Navbar.tsx** - Sticky navigation with gradient branding
- **Hero.tsx** - Hero section with gradient headline and CTAs  
- **LogoCloud.tsx** - Company logo trust badges
- **Features.tsx** - Feature showcase with icons
- **Process.tsx** - 3-step process section
- **Templates.tsx** - Template gallery
- **Testimonials.tsx** - Customer testimonials
- **Pricing.tsx** - Pricing plans
- **CTA.tsx** - Call-to-action section
- **Footer.tsx** - Site footer
- **Page.tsx** - Main page composition

## Color Palette

Primary gradient colors:
- Purple-600: #9333ea (rgb(147, 51, 234))
- Pink-600: #db2777 (rgb(219, 39, 119))

## Running the Prototype

```bash
npm install
npm run dev
```

Visit http://localhost:5000 to see the prototype landing page.
